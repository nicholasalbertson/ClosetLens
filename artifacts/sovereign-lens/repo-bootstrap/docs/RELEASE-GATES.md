# Release Gates

## Gate 0 — Repository integrity
- package installs cleanly
- tests pass
- no secrets in repository

## Gate 1 — Canon enforcement
- immutable identity policy cannot be changed through learning APIs
- standalone-image requirement preserved
- invalid gauge values rejected

## Gate 2 — Outfit intelligence
- style brief validates
- deterministic score is reproducible
- candidate mutations retain required slots
- hard constraints can veto a look

## Gate 3 — Proof jobs
- proof jobs are non-billable by default
- no provider key required
- proof output records validation state

## Gate 4 — Live generation
Blocked until a controlled matrix passes:
- identity fidelity
- tattoo continuity
- gauge anatomy
- wardrobe adherence
- single-image compliance

## Gate 5 — Autonomous promotion
Candidate policy or model changes must pass:
sandbox → regression → benchmark → shadow comparison → promotion.
