# SovereignCloset

Sovereign Closet is a personal appearance operating system and bounded recursive fashion intelligence platform.

## Core principle

LLM output is a proposal, not canonical truth.

The runtime follows:

**Observe → Hypothesize → Generate → Evaluate → Diagnose → Mutate → Validate → Promote → Remember**

Immutable identity rules are protected from autonomous mutation. Learnable state includes preferences, ranking weights, compatibility edges, retrieval weights, fit predictions, substitutions, and generation parameters.

## Initial implementation scope

- Canon and identity policy layer
- Typed style brief schema
- Product and outfit domain models
- Deterministic scoring
- Recursive outfit mutation
- Proof-job workflow
- FastAPI endpoints
- SQLite seed storage
- Verification tests
- GitHub Actions CI
