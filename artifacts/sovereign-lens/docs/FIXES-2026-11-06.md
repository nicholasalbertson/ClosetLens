# Fixes applied 2026-11-06

## Five open issues addressed

1. **Dedup** — Compose now tracks sorted item-ID signatures and skips duplicates. Owned-only no longer returns the same 4 items six times.
2. **Rotation** — Replaced `cands[i % len(cands)]` with `random.choice` per slot. Attempts up to 40 to find unique combinations.
3. **Scoring** — `score_outfit` now accepts optional `style_axes` dict. Identity and silhouette can be overridden from the request instead of pure hardcoded constants.
4. **Twin rules** — Twin bonus now inspects tags and product_type, not only name substrings. Partial credit if twin signals are weak. Constraints are enforceable via tags (`tunnel`, `frame`).
5. **PSD boxers** — P014 reclassified from `bottom` to `underwear`. Two owned outerwear pieces added (P056, P057) so owned seed is no longer zero outerwear.

## Additional
- Price handling: `None` treated as 0 so budget filtering does not skip items.
- Underwear excluded from main composition slots.

Local backend version bumped to 0.3.5.
