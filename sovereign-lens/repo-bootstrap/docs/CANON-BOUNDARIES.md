# Canon Boundaries

## Immutable by default

- Facial identity
- Identity continuity requirements
- Single-subject / standalone-image rule
- Protected tattoo concepts and spelling
- Gauge/tunnel terminal specification
- Protected visual signatures
- Safety and privacy policy
- Promotion/approval requirements

## Learnable

- Product metadata confidence
- Compatibility scores
- Retrieval weights
- User preference weights
- Context priors
- Outfit ranking
- Trend adjustments
- Model routing
- Generation parameters
- Fit estimates
- Product substitutions

## Rule

Learnable state may optimize inside Canon constraints but may not redefine Canon.
