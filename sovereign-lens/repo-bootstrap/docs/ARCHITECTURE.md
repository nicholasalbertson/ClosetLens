# Architecture

## System boundary

Sovereign Closet converts:

**user intent + identity state + wardrobe + market catalog + context + learned preferences**

into ranked, explainable, progression-aware looks.

## Recursive improvement loop

1. Observe
2. Hypothesize
3. Generate candidates
4. Evaluate
5. Diagnose
6. Mutate
7. Validate
8. Promote
9. Remember

Canonical identity policy is never automatically rewritten.
